# Student Result Analyzer

A beginner-friendly Python project that analyzes student academic performance based on marks obtained in different subjects.

## Features
- Accepts student name and ID.
- Takes marks for five subjects.
- Calculates total marks and percentage.
- Identifies the highest and lowest scoring subjects.
- Assigns performance remarks based on percentage.

## How to Run

1. Download the project.
2. Open the project folder.
3. Run the following command:

```bash
python student_result_analyzer.py
```
